# Nanova Infotech - Official Team Workspace & Portal

Comprehensive, fast, and secure Python FastAPI backend with SQLite & MongoDB database, JWT authentication, and built-in modern Admin & Employee Dashboards for Nanova Infotech.

---

## 🚀 How to Run the Project

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start the FastAPI Backend Server:**
   ```bash
   python run.py
   ```
   *or*
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

3. **Access the Portal in Browser:**
   - **Unified Login & Landing Page:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   - **Admin Dashboard:** [http://127.0.0.1:8000/admin.html](http://127.0.0.1:8000/admin.html)
   - **Employee Workspace:** [http://127.0.0.1:8000/dashboard.html](http://127.0.0.1:8000/dashboard.html)
   - **Interactive Swagger OpenAPI Docs:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
